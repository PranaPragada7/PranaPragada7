## About me

I build projects that connect models to useful products through clear
interfaces, reliable data flows, and maintainable backend systems. My work
spans generative AI, natural language processing, computer vision, application
security, and data-driven product development.

- Building LLM applications with tool calling, agents, MCP, and RAG
- Exploring adaptive learning, retrieval systems, and grounded AI workflows
- Applying deep learning to computer-vision and medical-imaging problems
- Designing APIs, persistence layers, automated tests, and security controls
